# Alberto Anelli — academic portfolio

A multi-page research portfolio prepared for GitHub Pages.

## Publish
1. Create a repository named **aanelli04.github.io** under the **aanelli04** account.
2. Upload the contents of this folder to the repository’s `main` branch.
3. In **Settings → Pages**, choose **GitHub Actions** as the publishing source.
4. The included workflow deploys on each push. The site will be at **https://aanelli04.github.io**.

## Add a project post
Open the project file under `projects/`. Under **Project updates**, duplicate an `<article class="update-post">...</article>` block, edit its date and text, and place it at the top of the list. Commit the change to publish it.

CV entries, publications and summaries are also plain HTML and can be edited directly.
