# Alberto Anelli — academic portfolio

Portfolio deployed at [aanelli04.github.io](https://aanelli04.github.io) with GitHub Pages.

## Update the CV
Replace `assets/cv/CV_Alberto_Anelli.pdf` with the new PDF, keeping the same filename, then commit and push. The CV page embeds this file and provides a download link.

## Add a journal article
Create an HTML page in `projects/posts/` using an existing article as a template, then add a card for it in `projects.html`. Use relative links and include references to relevant papers, projects or institutions.

## Update other site content
Home, CV summary, publications, awards, contacts and project pages are plain HTML. Keep summaries consistent with the attached CV. The site publishes automatically when changes are pushed to `main`.
